## What Nido records

| Area | What you get |
| --- | --- |
| **Feeding** | Breast and formula timers, side and session tracking, amounts |
| **Diapers** | Wet, soiled, dry and combinations |
| **Sleep** | Start/stop with live duration |
| **Growth** | Weight, height and head circumference against WHO and CDC percentiles |
| **Milestones & vaccinations** | Logging plus a schedule |
| **Photos** | Per-member avatars and uploads (MIME-validated) |
| **Journal & mood** | Free-form notes per day |
| **Shared access** | Invite caregivers, with owner / admin / member roles |
| **Reminders** | Inactivity and interval nudges |
| **Export / restore** | Move a family's whole dataset as JSON |
| **Offline queue** | Writes made without a connection are queued and replayed |
| **Themes** | 7 palettes × light and dark, plus a custom theme editor |

## The short version

```bash
git clone https://github.com/stewartshea/nido.git
cd nido
./scripts/init-env.sh   # writes .env with freshly generated secrets
docker compose up -d
```

Web client on [http://localhost:3001](http://localhost:3001), API health on
[http://localhost:3000/health](http://localhost:3000/health).

> **Read this before your first backup:** `NIDO_MASTER_KEY` is unrecoverable.
> Every family's database is keyed from it. Lose it and the data is gone, with
> no error to warn you first — see [Security model → the master key](./reference/security/#the-master-key).
