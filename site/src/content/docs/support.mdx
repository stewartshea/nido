## Why not Patreon

Short version: it is a membership platform, and this is not a membership.

- **Nido has nothing to ship members.** Patreon tiers exist because there is
  stuff behind them — early builds, private channels, badges, discounts. Here
  there is exactly one thing, the software, and it is already free. A tier would
  be a label on a donation.
- **It would be a dependency the project could not shed.** A hosted service in
  the path of a self-hosted tool is a single point of failure, and possibly a
  reason for the project to disappear. GitHub Sponsors has the same
  dependency, but it is the one the audience already has an account with.
- **It adds an account to a project whose premise is having none.** Nido has no
  third-party accounts and no social login. A recurring-membership subscription
  for a self-hosted app undercuts the argument it is making.

## What sponsorship pays for

The unglamorous work that keeps a dependency-bearing project safe:

- Security advisories in the SvelteKit, Node and SQLite trees
- Keeping these docs and the in-app guidance aligned with the code
- Reproducing the reports that arrive as "it broke during the 3am feed"
- CVE-digest releases nobody notices until the day they matter

## What it does not buy

- **No feature requests.** The [roadmap](./project/roadmap/) responds to what
  people actually hit. A concrete use case moves further than a larger invoice.
- **No priority support.** Issues are answered in the order they arrive; a
  reproducible bug report is worth more than any tier.
- **No guarantee.** Nido is maintained in one person's evenings, as-is, with no
  SLA.

## Ways to help that cost nothing

Often worth more than money, and much cheaper for a household with a newborn:

- **[Report a bug with a reproduction](./project/contributing/)** — vague reports
  are the main thing that slows fixes down
- **[Answer someone else's issue](./project/contributing/)** — you already hit
  it, so you know the answer
- **[Write a note about your setup](./project/roadmap/)** — "running on a
  Raspberry Pi with X" is genuinely useful information that does not exist
  anywhere else
- **[Star the repo](https://github.com/stewartshea/nido)** if that is what
  visibility means to you
